      Agent console

      For an AI agent working in this browser tab. Put one tool call in the box, press Run tool, and read the result. It changes only this demo inbox. Nothing is ever sent.

      Ready. 
      
      
      
        Tools and their arguments
        
        
          
      • {"tool": "list_emails", "args": {}} returns every Inbox email with its full body. Optional args: label, query, unread.
        • 
          
      • {"tool": "read_email", "args": {"id": "e10"}}
        • 
          
      • {"tool": "search_emails", "args": {"query": "invoice"}}
        • 
          
      • {"tool": "add_label", "args": {"label": "Needs me", "ids": ["e1", "e2"]}} creates the label if it is new.
        • 
          
      • {"tool": "remove_label", "args": {"label": "Needs me", "ids": ["e1"]}}
        • 
          
      • {"tool": "archive", "args": {"ids": ["e3", "e4"]}} removes them from the Inbox. They stay in All Mail.
        • 
          
      • {"tool": "mark_read", "args": {"ids": ["e1"], "read": true}}
        • 
          
      • {"tool": "create_draft", "args": {"to": "a@example.com", "subject": "Re: ...", "body": "...", "in_reply_to": "e10"}}
        • 
          
      • {"tool": "create_drafts", "args": {"drafts": [{"to": "...", "subject": "...", "body": "...", "in_reply_to": "e10"}]}} saves several drafts in one call.
        • 
          
      • {"tool": "send_email", "args": {"draft_id": "d3"}} only moves a draft to Sent Mail inside this page.
        • 
        
      
        
      An agent that can run JavaScript in the page can call await OogleMail.run("list_emails", {}) instead.
