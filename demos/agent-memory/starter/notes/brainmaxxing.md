# Brainmaxxing

Brainmaxxing is an open-source Markdown memory that gives an AI agent persistent memory, and the inspiration for this brain.

- Its repo description is "stupid simple persistent memory and skill improvement." ([source](https://github.com/poteto/brainmaxxing))
- It is a folder of Markdown notes that the agent reads at the start of a session and writes to when it learns something. ([source](https://github.com/poteto/brainmaxxing))
- Its author is Lauren Tan (GitHub `poteto`). ([source](https://github.com/poteto/brainmaxxing))
