# AI agent

An AI tool that does more than answer a question. Given a goal, it takes a series of steps on its own, such as looking things up, using other software and checking its own results. Builders often describe it as a model that uses tools in a loop.

Also called: agent, agents, agentic, autonomous agent.

**Example:** You ask an AI agent to find three venues for an event. It searches, compares prices, checks which dates are open and returns a shortlist.

**Connected on the map to:** LLM, Coding agent, Prompt, Agent loop, Subagent, Harness, AI, Tool use.
