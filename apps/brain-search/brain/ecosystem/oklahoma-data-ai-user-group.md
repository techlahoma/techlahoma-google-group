# Oklahoma Data & AI User Group

A free, in-person Oklahoma user group for people who use data and AI in their everyday work, formerly the Oklahoma Power BI and Fabric User Group. It does not allow vendor pitches unless someone asks, and its sessions have covered tools such as Databricks, Snowflake and Fabric. Its Meetup page says meetings alternate between Oklahoma City and Tulsa.

Also called: OK DAUG, Oklahoma Data and AI User Group, Oklahoma Power BI User Group, Oklahoma Power BI and Fabric User Group, OK Power BI User Group.

**Example:** A founder who sells to data teams attends an Oklahoma Data & AI User Group session to hear how analysts actually use AI at work.
