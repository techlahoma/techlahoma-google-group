# Prompt

The instructions or question you give an AI tool in everyday words. Clear, specific prompts get better results.

Also called: prompting, prompts, prompt engineering, instructions.

**Example:** Weak prompt: 'Make me a website.' Better prompt: 'Make a one-page site for a mobile dog groomer in Tulsa with services, prices and a booking request form.'

**Connected on the map to:** LLM, Code, Context window, Few-shot prompting, Temperature, AI, Vibe coding, AI agent.
