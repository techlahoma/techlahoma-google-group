# Google Developer Groups on Campus

Google's program for student developer groups at universities and colleges. Students in a chapter get hands-on experience with Google technologies and build skills for a tech career, and student leaders run each chapter.

Also called: GDG on Campus, GDGs on Campus, GDG on Campus chapter, Google Developer Group on Campus.

**Example:** A university student who wants to try Google's AI tools joins the Google Developer Groups on Campus chapter at her school and helps run a weekend build day.

**Connected on the map to:** Google, Meetup, User group, Talent, Hackathon.
