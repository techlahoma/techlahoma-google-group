# Tulsa AWS User Group

A Tulsa user group for people who build on Amazon Web Services and other cloud tools, part of the Techlahoma network. Discussed in the Techlahoma Slack as launched in October 2024 with sponsorship and support from Techlahoma, and as holding beginner sessions on AWS certifications at Gradient in 2025.

Also called: AWS Tulsa, Tulsa AWS, AWS user group, AWS meetup Tulsa, #tulsa-aws.

**Example:** A founder whose cloud bill doubled goes to a Tulsa AWS User Group meeting and asks how others keep costs down.

**Connected on the map to:** User group, Techlahoma user groups, Amazon Web Services, Cloud, Meetup, Techlahoma, Gradient, Startup ecosystem.
