# Firebase

Google's platform for building app back ends, with a database, login, file storage and hosting as managed services.

Also called: Fire base, Google Firebase, Firestore.

**Example:** A two-person team builds a mobile app on Firebase so they do not have to run their own servers.

**Connected on the map to:** Back end, Managed service, Google, Supabase, Authentication, MongoDB, Convex.
