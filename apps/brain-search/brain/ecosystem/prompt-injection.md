# Prompt injection

A security weakness in AI products. Text that a model reads changes its behavior in ways the builder did not intend. The text can come from the user or hide in outside content such as a web page or a file.

Also called: prompt injections, prompt injection attack, indirect prompt injection, injection attack.

**Example:** An AI assistant summarizes a web page. Hidden text on the page tells it to send the user's saved notes to a stranger. Without defenses, the assistant may follow that text.
