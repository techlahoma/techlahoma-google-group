# Tulsa Web Devs

Tulsa Web Devs is a Tulsa web developer Meetup group that belongs to the [Techlahoma](techlahoma.md) family of user groups.

- Its Meetup page says it aims to make Tulsa a leading city for web developers, with meetups on back-end languages, front-end technologies, data science and civic hacking.
- The Meetup page lists 1,545 members (checked 2026-11-18).
- The group is part of the Techlahoma Foundation; Techlahoma is a sponsor and a Super Organizer on the group.
- Recent events listed: "Data Jam: Decoding the Labor Market (JOLTS Edition)" (May 26, 2026), "Web Dev in 2026 - Questions & Curiosities" (Apr 28, 2026) and "Data Jam: Equity in Education" (Feb 24, 2026).
- Techlahoma's user groups page lists it at meetup.com/tulsa-web-devs.
