# GDG WordPress: Put Agent Skills to Work (Oct 29, 2026)

A [GDG Tulsa](../orgs/gdg-tulsa.md) and Tulsa WordPress community event on using AI agent skills for recurring website and content work.

- Date: Thursday, October 29, 2026, 6:00 to 8:00 PM (CDT).
- Venue: [Gitwit](../orgs/gitwit.md), 301 East Archer Street, Tulsa, OK 74120.
- Topic: turning repetitive tasks into reusable workflows with quality checks; the page pitches it as a chance to "turn a task you keep explaining into a workflow you can reuse." Attendees were invited to bring their own recurring tasks.
- Partners: [Techlahoma](../orgs/techlahoma.md); sponsor: Gitwit. Organizer: [Zain Khan](../people/zain-khan.md) (GDG Organizer).
- Related concept: [Agent Skills](../notes/agent-skills.md).
