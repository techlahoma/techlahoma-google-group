# Google Antigravity

Google Antigravity is Google's agentic development platform.

- Its site calls it "our agentic development platform, allowing anyone to build in the agent-first era."
- Products listed as of 2026-11-18: Antigravity App (runs several local agents at once, groups conversations into Projects, schedules routine tasks), Antigravity IDE ("the fully-featured, agentic IDE," with an agent manager and artifacts), Antigravity CLI (terminal-first), Antigravity SDK (custom agents in Python) and Antigravity Extensions.
- Platforms listed: macOS, Windows, Linux and Googlebook, plus a web app. For individual developers the site says "Available at no charge."
- A Google Developers Blog post dated May 19, 2026 announced that [Gemini CLI](gemini-cli.md) is transitioning to Antigravity CLI, which is "built in Go" and shares an agent harness with the Antigravity 2.0 desktop app. Agent Skills, Hooks, Subagents and Extensions (now "Antigravity plugins") carry over.
- The Antigravity Agent harness also powers [Google AI Studio](google-ai-studio.md) Build mode.
